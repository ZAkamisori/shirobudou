# 白葡萄

プロフィール・リンク・お知らせの1ページサイトです。スマートフォンにも対応しています。

## 編集
`content.js` の name、bio、links、news を編集します。SNS・pixiv・メッセージサイトの url にご自身のURLを入れるとリンクが有効になります。現在のプロフィール・お知らせは仮文です。

## GitHub Pagesで公開
1. GitHubでリポジトリを作成します。
2. このフォルダの中身（index.html、style.css、content.js、script.js、assets、.nojekyll）をリポジトリの最上位へアップロードします。
3. Settings → Pages → Build and deploymentで「Deploy from a branch」を選択します。
4. Branchは main、フォルダは / (root) を選び、Saveを押します。
5. 公開URLをムーンライトノベルズのプロフィール等に設定します。

## 素材
添付のタイトルロゴ.svg、購入素材の1.svg（猫）、4.svg（ハート）、5.svg（刺繍ライン）、9.svg（花瓶）、12.svg（星）、18.svg（宝石のライン）、19.svg（レース）を使用しています。購入素材は表示用PNGに変換しました。
購入素材を含むため、公開リポジトリに入れる前に購入元の利用規約（Web利用・素材の公開や再配布）をご確認ください。素材単独の再配布用ではありません。

インストール・ビルドは不要です。デザインを変更する場合は style.css を編集します。

見出し1・2・3には添付の数字バッジを使用しています。

装飾を追加した改訂版：楕円の枠、宝石のスプーン、チャームのライン、ティーカップのライン（7.svg・11.svg・13.svg・15.svg）を使用。リンク欄の各項目にもモチーフを添えています。
